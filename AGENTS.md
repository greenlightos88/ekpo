# EKPO Repository Instructions

Before writing, revising, critiquing, or restructuring EKPO:

1. Read `01_SCREENPLAY.fountain`.
2. Read every file in `docs/`.
3. Treat the screenplay and `docs/` together as the operational source of
   truth.
4. Do not silently contradict a `LOCKED` entry in
   `docs/DECISION_LOG.md`.
5. If a new user instruction conflicts with a locked decision, identify the
   conflict before changing it and record any explicit reversal.
6. Do not restore material removed from canon merely because it appears in an
   older draft, PDF, chat, or development file.

After every accepted screenplay revision, update:

- `docs/CURRENT_CONTINUITY.md`
- `docs/DECISION_LOG.md` when a consequential decision was accepted, rejected,
  or reversed
- `docs/MOTIF_LEDGER.md` when motif use changed
- `docs/NEXT_MOVEMENT.md`

`docs/EKPO_CONSTITUTION.md` changes only when the user explicitly changes a
permanent governing principle.
